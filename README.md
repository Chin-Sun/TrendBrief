# tech-news-digest · 技术热帖简报

一句话定位：一条自然语言指令，换回一份 20 条、带 200 字中文摘要的 NYT 风格 HTML 技术简报。

## 解决什么痛点

想跟进技术圈动态，就得挨个刷 Hacker News、r/LocalLLaMA、Hugging Face Papers、dev.to，四个站点四套热度口径，热帖混着噪音，读完还得自己翻译消化。本 skill 把这套动作压成一句话：抓取、去重、统一口径排名、写中文摘要、排版成页，全部自动完成。

## 快速开始

在 Claude Code 里直接说人话即可，无需手敲命令：

```
帮我出一份今天的技术新闻简报
```

Claude 会自动识别并加载本 skill，依次跑完取数、写摘要、渲染三段流程，最后 `open` 出 HTML 页面。

## 怎么唤起它

以下说法都会触发（skill 的 `description` 已登记这些语义）：

- 「技术新闻简报」「AI 资讯汇总」
- 「最新热帖」「今天有什么值得看的」
- 「爬这几个网站给我最新消息」
- 直接点名：「用 tech-news-digest 出一期」

**可选的附加指令**，写在同一句话里即可：

| 你想要的 | 这么说 |
|---|---|
| 指定输出文件名 | 「简报存成 `digest_0901.html`」 |
| 放宽 / 收紧 HN 门槛 | 「HN 门槛降到 10 分」 |
| 跳过正文抓取快速验证 | 「只跑排名，不抓正文」 |
| 传入浏览器导出的 Reddit 数据 | 「Reddit 数据用我这份 `top.json`」 |
| 改排名权重或名额 | 「转发量权重提到 0.4」（会先改 `references/ranking.md` 再改脚本） |

## 核心功能

- **四源统一抓取**：HN、r/LocalLLaMA、HF Papers、dev.to 一次拉齐，替代四个标签页来回切。
- **可解释的排名口径**：评论量 0.5 › 转发量 0.3 › 点赞量 0.2，同信源内做分位归一，缺失指标按比例重分配权重。只用平台原生真实计数，不构造代理指标。
- **名额制而非全局总榜**：七日要闻 10 条 + 三日速览 5 条 + HN 专栏 5 条，各信源固定名额，避免拿 HN 的 `points` 去减 dev.to 的 `reactions` 这类伪精度。
- **跨信源与跨版块去重**：同一篇论文同时上 HN 和 HF 时只留一条，并标注「另见 X」；一期 20 条互不重复。
- **200 字中文摘要**：由模型基于正文与 HN 热评撰写，讲清「讲了什么、为什么现在值得看、社区在争什么」。抓不到正文时如实标注，不编造。
- **Reddit 三模式降级**：凭证（首选）→ 浏览器导出 JSON → 跳过并在编者按显式说明本期未采集。

## 目录结构

```
.
├── SKILL.md                 # skill 定义与三段式工作流，Claude 实际读的就是它
├── references/
│   └── ranking.md           # 排名口径的唯一事实来源，改口径先改这里
└── scripts/
    ├── fetch_rank.py        # 抓取 → 去重 → 归一 → 打分 → 配额 → 正文提取
    └── render_html.py       # 渲染 NYT 风格 HTML
```

## 前置条件

- Python 3，仅用标准库，**无需 `pip install`**（环境无 requests/bs4）。
- Reddit 若要采集，需在 `~/.claude/.reddit_env` 配置 `REDDIT_CLIENT_ID`、`REDDIT_CLIENT_SECRET`、`REDDIT_UA`（UA 必须含用户名）。凭证只经环境变量传递，不写入产物、不打印、不进日志。
